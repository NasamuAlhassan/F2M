# Translating F2M

F2M speaks six languages: English, Twi, Ewe, Dagbani, Hausa and Kusaal. All
of them are in one set of catalogs (`packages/core/src/i18n/catalogs/*.json`)
that covers the SMS, USSD, voice **and** the web interface. The owner's
language Space translates them.

## Web pages: wrap every phrase a person reads

```tsx
import { useT } from '../lib/i18n';

export function MyPage() {
  const { t } = useT();
  return (
    <>
      <h1>{t('web.market.title', 'Marketplace')}</h1>
      <p>{t('web.market.lotsLive', '{n} lots live', { n: lots.length })}</p>
      <button>{t('web.common.signOut', 'Log out')}</button>
    </>
  );
}
```

- **Key:** `web.<page>.<name>`. Use `web.common.*` for words used on many pages.
  One key always means one English text.
- **English:** the second argument, written out in full. It is the source of
  truth and the fallback, so the page reads correctly before any translation
  exists. It must be a plain string, not built at runtime.
- **Values:** names, amounts, kilos, dates and lot codes go in as `{placeholders}`.
  They are never translated, so a number can't be mistranslated.
- **Leave untranslated:** people's and business names, lot codes, phone
  numbers, `GHS` amounts, and the brand name "Farm to Market".

## After adding or changing phrases

```bash
npm run i18n:extract   # collects every t('web…') phrase into en.json
npm run i18n:draft     # the Space translates whatever is new or changed, in all five languages
```

Changing an English phrase removes its old translations, so the next draft
redoes them.

## How a person chooses

- Farmers and drivers: the **Language** picker on their dashboard sets their
  SMS, USSD and call language **and** these screens.
- Everyone, signed in or not: the language row in the header. The choice is
  remembered in the browser.
- The server serves a language's phrases at `GET /api/i18n/web/<code>`.
  Anything not translated yet falls back to English phrase by phrase.

## The live switch

`I18N_DRAFT_LOCALES_LIVE=true` (D-049) puts the machine translations in front
of people. `false` returns every surface to English until a native speaker
reviews a catalog and sets its `_reviewed` field.
